Connect Instagram to Telegram

Automatically cross-post new photos, Reels and carousels from a public Instagram profile. A guided setup for GitHub Actions and Apify. Your account details stay in your browser.

1 Create your repository

Click the button to create your own copy. You will configure it in GitHub.

Create from template

After creating your copy, enable GitHub Actions if GitHub asks you. GitHub's scheduled runs may start later than the exact cron time.

2 Add your channels

Use one row per Instagram profile → Telegram channel pair. Accounts must be public. Add the bot as a channel administrator with posting permission.

To send the same Instagram profile to several channels, use separate repository deployments. We prevent duplicate usernames in one setup to avoid collisions in the duplicate tracker.

3 Copy the configuration

Open Settings → Secrets and variables → Actions → Variables in your new repository. Create a variable named ACCOUNTS_JSON with the value below.

Add your first account and select Generate configuration.

4 Add two secrets and run

  1. Get a Telegram bot from BotFather. Save its token as the GitHub Actions Secret TELEGRAM_BOT_TOKEN.
  2. Get an Apify API token. Save it as the Secret APIFY_TOKEN.
  3. In Actions → Instagram to Telegram → Run workflow, run once with initialize_only=true. This records old posts without sending them.
  4. Run once with dry_run=true to test without publishing. New content will then be checked about every six hours.
  5. Optional: set variable ALERT_CHAT_ID to a Telegram chat that should receive alerts after two consecutive failed syncs.

The wizard never asks you to paste a token or stores your entered accounts on a server. Apify has separate usage charges; check its pricing before enabling your workflow.
